<i>Apple Marcom (via Fractal), Senior ML Engineer, Jun 2025 - Mar 2026</i>

A multi-agent assistant that takes analysts' questions and routes them to the right analytical tools, so answers that used to take days of manual work come back in minutes.

- Multi-agent orchestration built on LangGraph, with fully async LLM, search and agent calls.
- A memory layer over Snowflake records and Keynote decks, with OpenSearch lookups across structured and unstructured indexes to pick the right tool for each query.
- A Snowflake MCP server for analysts, running under Apple's auth controls.
- Conversation memory in Redis for multi-turn context.
